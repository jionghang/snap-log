# 界面结构清单（分组 / 布局 / 文案）

这份清单是界面整理后的基线：每个页面有哪几组、每组有哪些行、文案怎么写的。
改动界面时按它对齐，避免再出现"同一页里两种风格"。

约定（全局一致）：

- **行**：左边灰色行标题（固定 148px 宽，放得下最长的"PaddleOCR 模型"而不折行），右边是控件；说明文字一律用灰色、限宽 500px 自动换行。
- **组**：加粗组标题 + 组间留白来区分（不加分隔线）；组间距约 20px，组内行距靠行的 Margin 控制。
- **按钮**：动宾短语，需要弹窗的一律带省略号（如"编辑…"）；主操作（保存设置 / 暂停记录 / 确定 / 删除确认里的删除）用默认按钮，其余为普通按钮。
- **数字与时间**：数字框后写单位；时间输入统一在框后标 `(HH:mm)`。
- **状态用中文**：已识别 / 无文字 / 失败 / 待识别（不再出现 Ok / Pending 这类枚举名）。

## 主窗口（SnapLog · 屏幕活动记录）

### 状态

- 运行概况（只读信息）
  - 运行状态：启动中（蓝）/ 运行中（绿）/ 已暂停（红）
  - 本次运行抓取：`{n} 条`
  - 最近一次抓取：`暂无记录` 或 `{时间} · {窗口标题}`
  - 总共抓取：`{n} 条`
- —— 1px 分隔线（把只读信息和可操作项分开）——
- 启动行为：`☐ 开机自动启动（登录后最小化到托盘）`（勾选即生效，写 HKCU 启动项）
- 操作按钮：`暂停记录`（运行中）/ `开始记录`（已暂停）、`立即抓取一次`（点后倒数 5 秒再抓，期间变成 `取消抓取`）
- 运行日志：标题 `运行日志（最近 500 条）` + 等宽字体日志列表
- 底部状态栏：`就绪`

### 抓取记录（记录查看器，与独立的记录查看器窗口同一套界面）

- 筛选区（两行）
  - 第一行：`☐ 按时间筛选` + 开始时间 至 结束时间（精度到分钟）
  - 第二行左侧（条件）：进程（默认"全部"）、状态（默认"全部"，中文选项）、关键词（占位"匹配窗口标题与识别文字"）
  - 第二行右侧（操作）：`查询`、`重置`、`导出 CSV`、`删除`（未选中记录时置灰）
- 列表列：时间（完整日期时间）、进程、窗口标题、字数、耗时(ms)、状态（中文）、识别文字摘要
- 详情：1px 分隔的详情标题 + `打开截图` / `打开截图目录`；内容是"记录 #id / 时间 / 进程 / 窗口标题 / 窗口类名 / 状态 / 字数 / OCR 耗时 / 抓取方式 / 图像尺寸 / 截图文件 / 提示·错误 / --- 识别文字 ---"
- 分页：`每页 [n] 条` + `|< 首页` `< 上一页` `下一页 >` `末页 >|` + `第 {n} / {m} 页，共 {x} 条`
- 空状态：`请在上方选择一行查看完整记录。`；空结果：`没有匹配的记录，可放宽时间范围或清空关键词。`

### 总结记录（与总结历史窗口同一套界面）

- 工具条（单行，用 22px 间隔把"看"和"做"分开）
  - 看：`☐ 只看成功`、`显示最近 [n] 条`、`刷新`
  - 做：`生成范围` + `☐ 只总结指定日期` + 日期选择器、`现在生成一次`、`删除`（未选中时置灰）
  - 右侧计数：`共 {n} 条` + `，其中失败 {n} 条`
- 列表列：开始时间、触发、结果、飞书（已写入/—）、模型、记录/图、耗时、内容摘要
- 详情标题 + `打开总结文件`（该条 .txt，无文件时置灰）/ `打开总结目录`
- 详情内容：`# 总结 #{id}`、开始时间、结束时间、触发来源、结果、模型、尝试次数、输入记录、耗时、飞书写入、覆盖范围、文件、说明、`总结正文`

### 抓取配置

- **抓取时机**：延时截图时长（毫秒，默认 5000）、抓取周期（分钟，默认 10）；组内首行说明"抓取由前台窗口切换驱动…"
- **截图与记录**：保存截图（复选框，含说明"保存截图文件，记录可追溯到当时的画面"）、截图目录（含"浏览…/打开"）、截图保留（天，0 表示永久保留）、记录保留（天，0 表示永久保留）
- 页脚：`保存设置`（无改动时置灰）/ `放弃修改`

### OCR 配置

- **文字识别**：OCR 引擎、识别模型、识别选项（`☐ 启用 MKLDNN 加速` + CPU 线程，说明在下一行）、识别方式（实时/每日定时批量 + 时间 `(HH:mm)`）、识别测试（`测试识别` 按钮 + 说明 + 引擎状态行）

### 大模型配置（四组）

- **模型与重试**：总结（`☐ 启用`）、模型列表（列表 + 添加…/编辑…/删除/上移/下移 + 说明）、失败重试（每个模型重试 n 次，起始间隔 n 秒（指数退避））
- **发送内容**：发送内容（仅发送识别文字 / 文字与截图 / 仅发送截图）、图片选项（同窗口图片间隔 n 秒、最多 n 张、清晰度）、随选择变化的说明
- **定时与提示词**：定时生成（`☐ 每天定时生成` + 时间 `(HH:mm)`，说明"按天补生成…"）、系统提示词（`编辑提示词…` + 状态"使用默认模板 / 已自定义"）
- **工作项目**：列表 + 添加…/编辑…/删除/上移/下移 + 说明

### 推送配置（三组）

- **写入内容**：写入内容（`☐ 将大模型生成的总结写入飞书多维表格` + 说明）、触发时机（每天 `(HH:mm)` + `☐ 生成总结成功后立即写入`）、写入范围（n 天内生成的总结）
- **连接参数**：应用凭证（App ID + App Secret，说明含环境变量与两层权限）、数据表（app_token + table_id + `读取表字段名`）、字段映射（列表 + 新增…/编辑…/删除/恢复默认 + 说明）
- **操作**：`测试连接`、`立即写入…`、待写入条数、App Secret 来源提示

### 关于

- 标题 SnapLog + 副标题"本机屏幕活动记录与工作总结工具" + 功能说明段
- 信息行：版本、运行时、系统（`Windows 10.0.19043.0（64 位）`）、构建时间（可执行文件时间，用来确认跑的是哪一版）、许可证 MIT
- 按钮：`打开项目主页` ｜ `打开数据目录`、`打开日志目录`、`打开总结目录`、`打开截图目录`
- 说明：数据归属（都在本机、默认不联网、何时才外发）+ 许可与源码
- 页脚：`保存设置` / `放弃修改`（本页无设置项，始终置灰）

## 独立窗口

| 窗口 | 结构 |
|---|---|
| 记录查看器（SnapLog 记录） | 与"抓取记录"页同一套界面 |
| 总结历史（总结历史） | 与"总结记录"页同一套界面；带总结目录入口 |
| 系统提示词 | 顶部一行说明（提示词会被原样发给模型，其余说明自动追加）+ 等宽编辑框 + `保存` / `恢复默认模板` / `取消` |
| 字段映射（新增/编辑字段映射） | 小结字段（下拉，带中文说明）+ 飞书字段名（可下拉选表内列名，也可留空）+ 两行提示 + `确定` / `取消` |
| 模型配置（模型配置 · 名称） | 名称 / 状态（`☑ 启用这个模型`）/ 接口地址 / 模型名称 / API Key / 密钥环境变量 + 提示 + `显示` / `测试连接` / `确定` / `取消` |
| 工作项目 | 项目名称 / 说明（多行）+ 提示 + `确定` / `取消` |
| 全部选项（高级） | 属性网格 + 说明 + `保存设置` / `从磁盘重新读取` / `关闭` |
| 识别测试（识别测试 · 进程名） | 截图与识别结果并排 + `复制文字` / `关闭` |
| 删除确认（删除记录 / 删除总结） | 将删除 N 条…+ `☐ 同时删除…（不可恢复）` + `删除` / `取消`（默认按钮是取消） |
| 提示与气泡 | 首次运行说明、定时任务完成/失败、写入飞书结果、开机自启动状态等 |

## 复查方式

- `SnapLog --ui-smoke`：构造并短暂显示各窗口，跑一批自动检查（状态一致性、无改动时保存按钮置灰、滚轮不改值、布局无零尺寸、窄窗口不溢出、提示词换行、删除按钮可用状态、构建时间）。
- `SnapLog --ui-shots [目录]`：把主窗口每个标签页（顶部 + 滚到底部各一张）、窄窗口下的关键页、以及各独立窗口截成 PNG，供人工复查（缺省写到数据目录的 shots）。
